# Конфиденциальность — Категории кешбэка

© 2026 ESI.Company. Приложение неофициальное и не связано с «Лентой», «Магнитом», «Пятёрочкой», X5 Group или Яндексом.

Приложение открывает официальные сайты `lenta.com`, `magnit.ru`, `x5club.ru`, `5ka.ru`, `bank.yandex.ru` и `sp.yandex.ru` во встроенном браузере. Вход в Яндекс также использует официальные страницы Яндекс ID. Данные для входа пользователь вводит в формы этих сайтов. Приложение не создаёт собственное поле пароля, не сохраняет пароль отдельно и не отправляет его на сервер ESI.Company. Каждый сайт обрабатывает вход и покупки по собственным правилам.

При запуске приложение обращается к GitHub Releases репозитория `vladyanych297-beep/cashback-categories-android`, чтобы проверить версию и скачать новую APK. Чеки, категории, данные входа и cookies в GitHub не передаются.

После нажатия «Обновить» приложение считывает доступные чеки и категории кешбэка или персональные предложения из открытых страниц личного кабинета. Для каждого магазина используется отдельное внутреннее хранилище. Данные сохраняются только на устройстве и применяются для локального расчёта рекомендаций. Приложение не использует аналитику, рекламу и собственный сервер для передачи чеков.

После расчёта приложение может автоматически выбрать или активировать рекомендованные категории на официальном сайте магазина от имени вошедшего пользователя. Повторное действие доступно по кнопке «Применить рекомендации сейчас».

В разделе Яндекс Пэй приложение сохраняет дату, сумму, название магазина или сервиса, банковскую категорию, идентификатор операции и признак оплаты картой Пэй. Эти данные применяются только для локального отчёта за 100 дней и рекомендаций. Приложение не выполняет платежи и переводы. Категории Яндекс Пэй пользователь выбирает самостоятельно на официальной странице.

Cookies и состояние входа хранятся в Android WebView. Удаление данных приложения или самого приложения очищает чеки, категории и состояние входа. Резервное копирование средствами Android отключено.
