# Релиз 1.3.5 для прямой установки APK

Релизный APK: `$env:USERPROFILE\Yandex.Disk\Distrib\lenta-cashback-1.3.5.apk`.

- Версия: 1.3.5, код 16.
- SHA-256 APK: `db54a5b7ba8f65698ffe9dd6ac7ae6a2c78c64ecb9edada42d93695193c52d79`.
- Основная подпись: ESI.Company, RSA 4096.
- SHA-256 сертификата ESI.Company: `bb35a524996e738c8f7bfc7a624cdee9196aab73f392168fc6f2a990e27c5e13`.
- APK содержит штатную цепочку смены ключа Android и обновляет обе ранее использовавшиеся подписи.
- Подтверждены схемы подписи APK v2, v3 и v3.1.

## Изменения

- При каждом запуске приложение проверяет GitHub Releases.
- Доступное обновление автоматически скачивается и передаётся системному установщику Android.
- На главном экране отображается результат проверки версии.
- Пятёрочка теперь считывает текущий и два предыдущих месяца через календарь X5 Клуба.
- Строка состояния показывает обрабатываемый месяц, этап «1 из 3» и номер чека.
- Параметры дат в адресе больше не используются: сайт X5 их игнорировал и оставлял только текущий месяц.
- Пустой месяц не прерывает синхронизацию следующих периодов.
- После синхронизации рекомендации применяются автоматически во всех трёх магазинах.
- Лента выбирает пять категорий в порядке ожидаемой выгоды.
- Магнит открывает полный список повышенных категорий, отмечает рекомендации и сохраняет выбор.
- Пятёрочка активирует подходящие персональные предложения.
- Добавлена кнопка повторного применения без повторного чтения чеков.
- Магнит и Пятёрочка анализируют покупки за последние три месяца.
- Для каждой рекомендации показывается ожидаемый кешбэк.

Файл `$env:USERPROFILE\Yandex.Disk\Distrib\lenta-cashback-1.3.5.apk.sha256` содержит контрольную сумму. Все следующие релизы создаются в этой же папке.
