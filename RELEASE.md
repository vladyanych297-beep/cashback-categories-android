# Релиз 1.3.7 для прямой установки APK

Релизный APK: `$env:USERPROFILE\Yandex.Disk\Distrib\lenta-cashback-1.3.7.apk`.

- Версия: 1.3.7, код 18.
- SHA-256 APK: `6ba359333462228647b659b0daec4877c536d281f78c71ca29bf3176f4b2fa38`.
- Основная подпись: ESI.Company, RSA 4096.
- SHA-256 сертификата ESI.Company: `bb35a524996e738c8f7bfc7a624cdee9196aab73f392168fc6f2a990e27c5e13`.
- APK содержит штатную цепочку смены ключа Android для обновления ранее установленных версий с сохранением данных.

## Изменения

- В Ленте, Магните и Пятёрочке добавлен отчёт «Покупки по категориям кешбэка».
- Покупки распределяются по категориям, загруженным из личного кабинета соответствующего магазина.
- Отчёт показывает общую сумму товаров, число чеков и позиций за выбранные даты, суммы по каждой категории в порядке убывания.
- Даты начала и окончания выбираются через календарь и сохраняются отдельно для каждого магазина. Есть сброс к периоду по умолчанию.
- Кнопка «Товары» раскрывает список покупок категории с суммами. Повторные покупки одного товара объединяются.
- Доступные категории без покупок можно раскрыть отдельно.
- Товары без сопоставленной категории кешбэка показаны отдельными суммой и списком.
- Суммы рассчитываются в копейках; повторные чеки исключаются.
- Товары, подходящие к нескольким категориям, показаны в каждой. Общая сумма учитывает каждый товар один раз; пересечение категорий отмечено в интерфейсе.
- Период отчёта применяется к сохранённым чекам. Для дополнительной истории и актуальных категорий используется «Обновить».
- По умолчанию в Пятёрочке используется период последних 100 дней, включая сегодня.

## Проверка

- Автоматические проверки покрывают границы периода, расчёт сумм, повторные чеки и товары, пересечение категорий, позиции без категории, округление и пустую историю.
- На телефоне проверены отчёты всех трёх магазинов, смена дат и раскрытие товаров категории.
- В Ленте изменение периода увеличило число выбранных чеков с 26 до 27 и пересчитало итог с 89 233,66 ₽ до 92 468,09 ₽.
- В Магните подтверждены итог 12 744,82 ₽ по 53 чекам и товар внутри категории «Персил для стирки» на 899,99 ₽.

Приложение проверяет обновления в GitHub Releases при запуске. Установка требует системного подтверждения Android.

Все релизы сохраняются в `$env:USERPROFILE\Yandex.Disk\Distrib`; в папке распространения оставляются только актуальный APK и его контрольная сумма.
