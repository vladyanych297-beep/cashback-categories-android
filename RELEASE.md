# Релиз 1.3.6 для прямой установки APK

Релизный APK: `$env:USERPROFILE\Yandex.Disk\Distrib\lenta-cashback-1.3.6.apk`.

- Версия: 1.3.6, код 17.
- SHA-256 APK: `b4f0200945d3c80978f99f0c7dc915ff1fb2f11aaad58e30ed4b3428c3373afe`.
- Основная подпись: ESI.Company, RSA 4096.
- SHA-256 сертификата ESI.Company: `bb35a524996e738c8f7bfc7a624cdee9196aab73f392168fc6f2a990e27c5e13`.
- APK содержит штатную цепочку смены ключа Android для обновления ранее установленных версий с сохранением данных.

## Изменения

- Пятёрочка загружает чеки за последние 100 дней, включая текущий день.
- Календарь X5 Клуба последовательно переключается на все месяцы, пересекающиеся с диапазоном. Их может быть четыре или пять.
- На 28 сентября 2026 года диапазон составляет 21 июня — 28 сентября: считываются сентябрь, август, июль и июнь.
- Чеки до начала диапазона, будущие даты и некорректные даты исключаются из локальной истории Пятёрочки.
- Рекомендации и автоматическая активация предложений Пятёрочки учитывают покупки в том же диапазоне 100 дней.
- Строка состояния показывает текущий месяц, общее число месяцев и период 100 дней.
- При чтении чека год берётся из выбранного месяца, включая переход между годами.
- Проверены границы периода и полнота набора месяцев на каждой дате 2024–2027 годов.

Приложение проверяет обновления в GitHub Releases при запуске. Установка требует системного подтверждения Android.

Все релизы сохраняются в `$env:USERPROFILE\Yandex.Disk\Distrib`; в папке распространения оставляются только актуальный APK и его контрольная сумма.

Политика обработки данных: [PRIVACY.md](PRIVACY.md).
