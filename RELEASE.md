# Релиз 1.3.10 — восстановление синхронизации Ленты

- Версия: 1.3.10, код 21.
- APK: `$env:USERPROFILE\Yandex.Disk\Distrib\lenta-cashback-1.3.10.apk`.
- SHA-256 APK: `28e1e018e09cc3f3634db4a1f80cc6bc7f9846c4a92841cfdc6bde31844a23b1`.
- Подпись: ESI.Company. Обновление устанавливается поверх предыдущей версии с сохранением данных.

## Изменения

- Поддержан новый мобильный адрес личного кабинета Ленты `/my-account-mobile/`. Перенаправление на него больше не вызывает ошибочное требование повторного входа.
- Чтение истории поддерживает оба названия вкладки магазина: «Магазин» и «Магазины».
- Адреса мобильной и обычной версии одного чека приводятся к единому виду, чтобы не создавать дубликаты при обновлении.
- Устранена причина зависания при открытии большого отчёта: правила сопоставления и нормализованные названия используются повторно, убран повторный расчёт при первом открытии Ленты.
- Выбор категорий по-прежнему требует подтверждения пользователя.

## Проверка

- Проверены оба названия вкладки, поиск ссылок на чеки, чтение товаров мобильного чека и единый идентификатор покупки.
- На подключённом телефоне проверены открытие Ленты без зависания и чтение покупок после перенаправления в мобильный кабинет.
- Релизный APK собран и подписан; обновление сохраняет данные версии 1.3.9.

При запуске проверяется актуальный релиз GitHub. Android может запросить системное подтверждение установки.

В папке Distrib оставляются актуальный APK приложения и его контрольная сумма.
