# Релиз 1.3.8 для прямой установки APK

Релизный APK: `$env:USERPROFILE\Yandex.Disk\Distrib\lenta-cashback-1.3.8.apk`.

- Версия: 1.3.8, код 19.
- SHA-256 APK: `85e3617a9933e7a24edd299d63e8d42b1694ce6b5e0547a92d3a7cc14c39afbd`.
- Основная подпись: ESI.Company, RSA 4096.
- SHA-256 сертификата ESI.Company: `bb35a524996e738c8f7bfc7a624cdee9196aab73f392168fc6f2a990e27c5e13`.
- Сохраняется цепочка смены ключа Android для обновления прежних версий с сохранением данных.

## Изменения

- Добавлен автономный раздел Яндекс Пэй: вход на официальном сайте, история операций за 100 дней, суммы по банковским категориям, магазины и сервисы внутри каждой категории.
- Доступные предложения Яндекс Пэй сравниваются с историей. Учитывается источник оплаты: карта Пэй либо карта любого банка. Скидка на доставку отделена от кешбэка.
- Категории Яндекс Пэй пользователь подтверждает самостоятельно на официальной странице.
- Исправлено сопоставление покупок с категориями Магнита и Пятёрочки. Добавлены правила для ухода за волосами, бытовой химии, молочных продуктов, напитков, мороженого, выпечки и предложений брендов. Нормализуются неразрывные пробелы и буква «ё».
- В Пятёрочке считываются любимые категории кешбэка X5. При наличии выбора на следующий месяц открывается этот период, учитывается лимит сайта. Сохраняется анализ чеков за 100 дней.
- В Магните исключается предложение подписки и устраняются повторные названия при чтении категорий.

## Проверка

- Проверки сумм и сопоставления проходят: даты, повторные покупки, копейки, Unicode, товарные виды, бренды и исключения.
- Проверки Яндекс Пэй проходят: 100 дней, источники оплаты, банковские категории, переводы, дубликаты, скидки, даты Москвы, календарь и прокрутка.
- На подключённом телефоне подтверждено появление рекомендации Магнита по сохранённым покупкам.
- В Пятёрочке подтверждены чтение категорий октября, рекомендации по сохранённым чекам, сохранённый выбор трёх категорий на сайте и повторное чтение без ручного открытия списка.
- На телефоне подтверждена полная синхронизация Яндекс Пэй за 100 дней: вход, период с 22 июня по 29 сентября, дозагрузка истории при прокрутке, 12 доступных категорий и рекомендации.
- APK собран, подписан, проверен и установлен поверх прежней версии с сохранением чеков.

Приложение проверяет обновления в GitHub Releases при запуске. Android может потребовать системного подтверждения установки.

В папке распространения остаются только актуальный APK приложения и его контрольная сумма. Суммы предложений могут пересекаться; фактическое начисление зависит от правил сервиса.
