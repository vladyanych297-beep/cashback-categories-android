# Категории кешбэка — Android

![Иконка приложения](res/drawable-nodpi/app_icon.png)

[Скачать последнюю версию](https://github.com/vladyanych297-beep/cashback-categories-android/releases/latest) · [Политика конфиденциальности](PRIVACY.md) · [Описание релиза](RELEASE.md)

Приложение состоит из трёх автономных разделов: **Лента**, **Магнит** и **Пятёрочка**. У каждого раздела отдельный вход, история чеков, список категорий и локальные рекомендации. Данные одного магазина не смешиваются с данными другого.

Вход выполняется на официальной странице магазина во встроенном браузере. Приложение не создаёт собственные поля пароля и не отправляет чеки на сервер ESI.Company. После нажатия «Обновить» оно считывает доступные чеки и актуальные категории или персональные предложения, сохраняет их только на телефоне и оценивает выгоду по истории покупок.

При каждом запуске приложение проверяет последнюю версию в GitHub Releases. Новая APK скачивается автоматически, после чего Android показывает системное подтверждение установки. При первом обновлении нужно разрешить установку из приложения «Категории кешбэка».

## Магазины

- **Лента** — магазинные чеки и категории кешбэка Ленты. Существующие локальные данные прежней версии сохраняются при установке отладочного обновления поверх неё.
- **Магнит** — история операций и товарные категории «Магнит Плюс». Карточки подписки исключаются из товарных категорий.
- **Пятёрочка** — чеки Пятёрочки из X5 Клуба за последние 100 дней, включая сегодня, и персональные предложения с баллами на `5ka.ru`. Загружаются все месяцы, пересекающиеся с этим диапазоном; более старые чеки исключаются из локальной истории и рекомендаций.

Экран остаётся включённым, пока приложение открыто. После выхода действует системная настройка отключения экрана.

## Покупки по категориям кешбэка

В обзоре каждого магазина показан отчёт по категориям кешбэка, загруженным из его личного кабинета. Можно выбрать начальную и конечную даты; выбранный период сохраняется отдельно для каждого магазина. По умолчанию используются период анализа магазина и текущая дата, в Пятёрочке — последние 100 дней.

Отчёт показывает сумму товаров с копейками, число чеков и позиций, суммы по всем доступным категориям в порядке убывания. Кнопка «Товары» раскрывает названия и суммы покупок внутри категории; повторные покупки одного товара объединяются. Категории без покупок можно раскрыть отдельной кнопкой. Для товаров, не сопоставленных с доступными категориями, показаны отдельные сумма и список.

Расчёт выполняется по сохранённым чекам: выбор периода отчёта не загружает дополнительную историю и не меняет период рекомендаций. Для новых чеков и категорий нажмите «Обновить». Товар может подходить к нескольким категориям кешбэка; тогда он показан в каждой, но общий итог учитывает его один раз. Соответствие категории определяется по названию товара, точные правила начисления устанавливает магазин.

## Сборка и установка

Нужны JDK 21 и Android SDK с `platforms/android-36` и `build-tools/36.1.0`.

```powershell
cd cashback-categories-android
.\build.ps1
adb install --user 0 -r .\build\lenta-cashback-debug.apk
```

Релизная сборка для прямой установки:

```powershell
.\build.ps1 -Release
```

Готовый релиз сохраняется в `$env:USERPROFILE\Yandex.Disk\Distrib\lenta-cashback-<версия>.apk`. Все следующие релизные сборки автоматически сохраняются в эту папку. Готовые APK также публикуются в [GitHub Releases](https://github.com/vladyanych297-beep/cashback-categories-android/releases). Сведения о подписи находятся в [RELEASE.md](RELEASE.md), обработка данных — в [PRIVACY.md](PRIVACY.md).

- Java-код и ресурсы собраны без ошибок; APK подписан и проверен `apksigner` по схемам v2 и v3.
- Сценарии истории, деталей чека и категорий Магнита и Пятёрочки проходят отдельную проверку синтаксиса.
- На открытом личном кабинете Магнита подтверждены 53 операции и 43 доступные категории; структура товара, даты и суммы проверена на странице чека.
- На открытом X5 Клубе подтверждены история Пятёрочки, дозагрузка чеков и чтение 4 товаров из чека. На `5ka.ru` подтверждены персональные предложения с процентом и названием категории.
- Пятёрочка автоматически выбирает в календаре X5 все месяцы последних 100 дней. В предыдущем релизе на физическом телефоне подтверждены переходы «Сент» → «Авг» → «Июль»; число сохранённых чеков выросло с 9 до 15 без дубликатов.
- Во время синхронизации строка состояния показывает название месяца, его номер в диапазоне и текущий чек.
- На физическом телефоне подтверждены проверка GitHub Releases, определение актуальной версии и установка APK с объединённой цепочкой подписей без потери 15 сохранённых чеков.
- На физическом телефоне сохранены 27 чеков и 36 категорий Ленты. Полная синхронизация требует входа в каждый магазин внутри WebView приложения.
- Магнит сравнивает повышенные категории с уникальными покупками за последние три месяца, Пятёрочка — за последние 100 дней. Оба раздела показывают предполагаемый кешбэк.
- Повторная синхронизация распознаёт одинаковые чеки и не удваивает суммы.
- После обновления приложение автоматически применяет подходящие рекомендации: выбирает пять категорий Ленты, сохраняет чекбоксы Магнита и активирует персональные предложения Пятёрочки.
- Названия товаров сопоставляются с категориями локальными правилами. Точное начисление определяет торговая сеть, поэтому рекомендация является оценкой.
