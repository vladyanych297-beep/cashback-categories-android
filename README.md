# Категории кешбэка — бесплатная версия RuStore

© 2026 ESI.Company.

Ветка `codex/rustore-free` предназначена для подготовки бесплатного приложения к публикации в RuStore. Базовая версия проекта сохранена в `main`.

## Возможности

Три автономных раздела в порядке: **Лента → Магнит → Пятёрочка**. Для каждого магазина доступны вход на официальном сайте, чтение чеков, суммы покупок по категориям кэшбэка и рекомендации. История и настройки разделов хранятся отдельно на телефоне.

- Лента: магазинные чеки, анализ за последние 90 дней и актуальные категории.
- Магнит: история операций, анализ за последние три месяца и товарные категории «Магнит Плюс».
- Пятёрочка: чеки за последние 100 дней с загрузкой всех пересекающихся месяцев и категории X5 Клуба.

Категории привязаны к фактическому месяцу на сайте. После расчёта пользователь проверяет и подтверждает выбор. Если магазин уже закрыл выбор, отображаются действующие категории. Оценка соответствия товаров строится по названиям; условия начисления устанавливает магазин.

Приложение бесплатное, без рекламы, подписок и встроенных покупок. Банковские интеграции и установка APK из GitHub отсутствуют. Обновления этой редакции предполагается распространять через RuStore. SDK обновлений магазина пока не подключён.

## Сборка

Нужны JDK 21 и Android SDK: `platforms/android-36`, `build-tools/36.1.0`.

```powershell
.\build.ps1
.\build.ps1 -Release
```

Отладочный APK: `build/lenta-cashback-debug.apk`.

Подписанная сборка: `C:\Users\Vlady\Yandex.Disk\Distrib\RuStore\lenta-cashback-1.3.11-rustore-free.apk` и файл контрольной суммы. Имя пакета сохранено: `ru.local.lentacashback`. Перед первым публичным релизом необходимо назначить следующий `versionCode` и проверить совместимость подписи.

## Подготовка публикации

Пока это отдельная рабочая редакция, а не опубликованный релиз RuStore. Дальнейшая подготовка: демонстрационный режим, защита локальной истории, удаление данных, публичная политика конфиденциальности, материалы карточки и проверка подписи для магазина.
